# SprayFight: согласованная раскладка MacBook

Зафиксировано 11.10.2026. Целевая сборка: `play/`, ветка
`sprayfight-open-world-slice`. Старые резервные прототипы не меняются.

Источник: рабочий конфиг Getting Up
`/Users/nathanieltorb/GettingUp-RE-Workspace/game/engine/binds_pc.cfg`
и официальный `GameInfo/ReadMe.txt`; исследовательская запись:
`/Users/nathanieltorb/GettingUp-ReverseEngineering/docs/re/KEYBOARD_LAYOUT_MACBOOK.md`.
U/O и IJKL — наши добавленные в оригинальную игру клавиши для MacBook,
не заводская раскладка. Используется физический `KeyboardEvent.code`,
поэтому язык клавиатуры не влияет на WASD.

## Подключено к существующим действиям

| Клавиши | Действие прототипа |
|---|---|
| WASD | Ходьба; у стены A/D — шаг, W/S — высота точки краски |
| Левый Ctrl, один раз | Переключить ходьбу/бег; автоповтор не переключает повторно |
| Shift, удерживать | Красться; пока используется существующее пригнутое движение |
| Space | Прыжок / существующее преодоление препятствия |
| E / Q | Взаимодействие с соперником или стеной; отход от стены |
| V, удерживать у стены | Войти в рисование; отпускание выводит из свободного рисования |
| V + U | Обычная подача краски |
| V + O | Быстрая подача краски |
| I / K, J / L | Камера вверх/вниз, влево/вправо |
| Escape | Отход от стены в свободном режиме (не полноценная пауза) |

В баттле отпускание V прекращает клавиатурную подачу, но не отменяет раунд.
Мышь/трекпад и тач сохраняют прежний путь входа через взаимодействие и
рисование указателем. Поэтому V обязателен для U/O, но не для тач-рисования.
Тач-присед и вытягивание руки используют отдельные виртуальные действия:
Ctrl и Shift больше не конфликтуют с тач-кнопками.

Камера пока меняет направление взгляда, не реализует полный оригинальный
орбитальный контроллер; движение WASD остаётся в мировых координатах.
У стены сохраняется существующий конус ±30°. Знаки IJKL в оригинале
не подтверждены поклавишным runtime-протоколом.
Быстрая подача ×1.5 и расход ×1.5 — временная настройка прототипа,
**не доказанный коэффициент Getting Up**. Прогрессионное открытие ещё не реализовано.
Wheatpaste остаётся прежним инструментом прототипа: отдельные стадии
«U — клей, O — постер» ещё не перенесены.

## Зарезервировано: механика ещё не реализована

| Клавиши | Целевая роль Getting Up |
|---|---|
| U / O вне рисования | Удар / пинок |
| F | Интуиция |
| Tab | Инвентарь |
| ↑ | Перекат |
| Z / X | Выглядывание |
| 1 / 3 | Цвет в свободном граффити или размер шаблона |
| 2 / 4 | Стиль |
| C / B / T | COMMAND_CAMERA / EXT_5 / TOGGLEHELD; точная роль требует проверки |

Эти назначения не заменяются несвязанными действиями. Нажатия зарезервированных
клавиш показывают сообщение о недоступной механике. Бой U/O вне стены пока не работает.

## Дополнительные клавиши только для прототипа

R — встряхивание (перенесено с F); 6/7/8 — баллон/валик/расклейка;
9/0 — fat/skinny cap; G — существующий выбор Go Big до рисования.
Это не оригинальные бинды. Смена инструментов/кэпов также доступна через UI.

## Проверка

`node --test tests/sprayfight-input.mjs` — комбинации V/U/O, камера,
Shift и резервирование конфликтующих клавиш. Это автоматическая проверка
логики ввода, не доказательство соответствия анимаций оригиналу.
Ручной сценарий: начать игру → Ctrl → WASD → Shift → Space → подойти к стене →
удерживать V → U/O → W/S → IJKL → отпустить V; отдельно проверить тач и
отпускание клавиш/кнопок при потере фокуса.
